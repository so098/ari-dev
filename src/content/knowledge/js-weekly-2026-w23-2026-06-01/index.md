## 용어 정리 콜아웃
> **RSC**: React Server Components. 서버에서 컴포넌트를 렌더링해 전송량과 초기 로딩 비용을 낮추는 패턴.
> **Tree Shaking**: 사용하지 않는 코드를 번들에서 제거해 용량을 줄이는 최적화 기법.
> **DX**: Developer Experience. 개발 생산성과 편의성 전반을 뜻함.
